# Changelog

All notable changes follow semantic versioning.

## [0.1.0] - 2026-08-03

### Added

- Callable root skill and bounded stage-skill contracts.
- Python CLI for profile validation, project initialization, project validation, stage transitions, and integrity locks.
- Schema-governed `ai-innovation` profile.
- Fail-closed state machine and stale-lock detection.
- Golden-project integration tests and cross-platform adapter manifests.

### Limitations

- Formal search, screening, extraction, R synthesis, robustness analysis, Quarto reporting, and submission-package generation are not implemented.
