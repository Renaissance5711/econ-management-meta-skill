# Changelog

All notable changes follow semantic versioning.

## [0.2.0] - 2026-08-03

### Added

- Immutable, schema-validated protocol versions and classified amendments.
- Search-run provenance and CSV, RIS, BibTeX, and EndNote XML import.
- Deterministic report-level deduplication with retained provenance and conflict logs.
- Independent human title/abstract and full-text screening with agreement and adjudication.
- Human-verified report-family and study-family reconciliation.
- Dual extraction, conflict detection, human resolution, and verified-only export.
- CLI command groups for protocol, search, screening, report families, and extraction.

### Limitations

- Live search, active learning, PDF extraction, construct/estimand gates, effect-size computation, R synthesis, robustness models, and Quarto reporting remain unavailable.

## [0.1.0] - 2026-08-03

### Added

- Callable root skill and bounded stage-skill contracts.
- Python CLI for profile validation, project initialization, project validation, stage transitions, and integrity locks.
- Schema-governed `ai-innovation` profile.
- Fail-closed state machine and stale-lock detection.
- Golden-project integration tests and cross-platform adapter manifests.

### Limitations

- Formal search, screening, extraction, R synthesis, robustness analysis, Quarto reporting, and submission-package generation are not implemented.
